# Docker & CI/CD

## Docker Setup

The project uses multi-stage Docker builds for production deployment.

### Services

`docker-compose.yml` defines four services:

| Service         | Image               | Port     | Purpose                 |
| --------------- | ------------------- | -------- | ----------------------- |
| postgres        | postgres:16-alpine  | internal | Ponder indexer database |
| indexing-server | Custom (Node 24)    | 42069    | Ponder GraphQL API      |
| hola-modern     | Custom (nginx:1.27) | internal | Static frontend         |
| nginx           | nginx:1.27          | 80, 443  | Reverse proxy           |

### Build

```bash
docker compose build \
    --build-arg VITE_WALLETCONNECT_PROJECT_ID=your_id \
    --build-arg VITE_INDEXER_URL=https://your-indexer.com

docker compose up
```

### Architecture

```
Internet → nginx (80/443)
            ├── /api/* → indexing-server (42069)
            └── /*     → hola-modern (static)

indexing-server → postgres (5432)
indexing-server → RPC endpoint (external)
```

## CI/CD (GitHub Actions)

### PR Workflow

On every PR to `dev` or `main`, the `main-workflow.yml` orchestrates:

1. **Build** — Install deps (Node 24, pnpm, Foundry), compile, type-check
2. **Lint** — ESLint + Prettier
3. **Test** — Vitest unit tests
4. **Integration tests** — Contract integration tests
5. **E2E tests** — Playwright with Chromium

Concurrency groups cancel in-progress runs on the same branch.

### IPFS Deployment

Frontend deploys are **not** run in CI — they go through a local script, [`scripts/deploy-ipfs.sh`](https://github.com/hollab-io/hollab-cannes-26/blob/dev/scripts/deploy-ipfs.sh), so the deployer key never lives in CI and every production push is multisig-approved. The script:

1. Builds the frontend with production env vars (`pnpm --filter hola-modern build`)
2. Pins `dist/` to IPFS via **omnipin** (Filecoin pinning)
3. Emits the new CID plus the encoded `setContenthash` calldata for a human-signed **Safe** transaction that updates the `hollab.eth` ENS **contenthash**

Required env (local shell, not CI secrets):

-   `OMNIPIN_FILECOIN_TOKEN` — Filecoin pinning API token
-   production `VITE_*` build vars (gateway, indexer URLs, WalletConnect project id) — typically in `apps/hola-modern/.env.production`

See [IPFS Deployment](/operations/ipfs) for the full flow.
