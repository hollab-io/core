# Agent SDK

The `@hollab-io/agent-sdk` package provides a unified, framework-agnostic API for AI agents and automated systems to interact with hollab.eth governance.

## Installation

```bash
pnpm add @hollab-io/agent-sdk viem
```

## Quick Start

```ts
import { HollabAgent } from "@hollab-io/agent-sdk";
import { createPublicClient, createWalletClient, http } from "viem";
import { privateKeyToAccount } from "viem/accounts";
import { sepolia } from "viem/chains";

const account = privateKeyToAccount("0x...");

const agent = new HollabAgent({
    walletClient: createWalletClient({
        account,
        chain: sepolia,
        transport: http(),
    }),
    publicClient: createPublicClient({
        chain: sepolia,
        transport: http(),
    }),
    indexerUrl: "https://indexer.hollab.eth/graphql",
    orgFactoryAddress: "0x...",
});
```

## Modules

The `HollabAgent` class exposes six modules:

| Module             | Purpose                                                                        |
| ------------------ | ------------------------------------------------------------------------------ |
| `agent.org`        | Create organizations, manage members                                           |
| `agent.roles`      | Query roles by org or team                                                     |
| `agent.circles`    | Query teams (circles)                                                          |
| `agent.meetings`   | Start/end syncs and proposal reviews, record outputs                           |
| `agent.governance` | Drive the proposal lifecycle (create, raise/resolve objection, adopt, discard) |
| `agent.voting`     | Create votes, cast votes, manage collaborator weight                           |

## Reading Data

All read operations query the Ponder indexer via GraphQL:

```ts
// Get org details
const org = await agent.org.get("1");

// List all roles in an org
const { items: roles } = await agent.roles.listByOrg("1");

// List teams
const { items: teams } = await agent.circles.listByOrg("1");

// List members
const { items: members } = await agent.org.listMembers("1");

// List votes
const { items: votes } = await agent.voting.listByCircle(votingAddress, "1");
```

## Managing Organizations

```ts
// Create a new org (clones OrganizationInstance + RoleRegistry, deploys
// governance token, registers ENS subname). Returns both the orgId and the
// per-org OrganizationInstance address — the one-stop target for membership
// writes, join requests, admin ops, and agent identity links.
const { orgId, instance } = await agent.org.create("mydao", "Our purpose", {
    tokenName: "My DAO Token",
    tokenSymbol: "MDAO",
});

// Add / remove members — call on the OrganizationInstance clone.
await agent.org.addMember(instance, "0xAlice...");
await agent.org.removeMember(instance, "0xBob...");

// If you only have the orgId, resolve the instance from the factory directory:
const instance = await agent.org.resolveInstance(orgId);
```

## Running Meetings

```ts
// Start a team sync
const { meetingId } = await agent.meetings.startSync(meetingFactoryAddr, orgId);

// Record outputs during the sync
await agent.meetings.recordOutput(meetingFactoryAddr, {
    meetingId,
    outputType: 0, // 0=NextAction, 1=Project, 2=Request, 3=Information
    description: "Publish blog post by Friday",
    assignedTo: "0xAlice...",
});

// End the meeting
await agent.meetings.end(meetingFactoryAddr, meetingId);
```

## Governance Proposal Lifecycle

All structural changes flow through the on-chain proposal lifecycle: `createProposal` → (optional `raiseObjection` / `resolveObjection`) → `adoptProposal` or `discardProposal`. The agent-sdk mirrors this surface one-to-one — there is no "do it in one call" shortcut, and `executeGovernance` no longer exists. Callers wanting atomic create+adopt can batch the two writes (viem multicall, `wallet_sendCalls`) or issue them sequentially.

```ts
import { ChangeType, encodeCreateRole } from "@hollab-io/agent-sdk";

// 1. Any member creates a Draft proposal. tensionText is hashed client-side
//    with keccak256 — only the hash is committed on-chain. Pass tensionHash
//    directly if the full text is already pinned to IPFS / 0G.
const { proposalId } = await agent.governance.createProposal(meetingFactoryAddr, {
    orgId,
    circleId: 1n,
    proposerRoleId: 0n,
    tensionText: "Marketing cadence is unclear",
    changeType: ChangeType.CreateRole,
    changeData: encodeCreateRole({
        circleId: 1n,
        name: "Marketing Lead",
        purpose: "Drive community growth",
        accountabilities: ["Social media strategy", "Content calendar"],
    }),
});

// 2. Any member can object while the proposal is still Draft.
const { objectionId } = await agent.governance.raiseObjection(meetingFactoryAddr, proposalId, {
    text: "This overlaps with the existing Comms role",
});

// 3. The original objector (withdrawal) or an org admin (integration
//    confirmed) can resolve the objection.
await agent.governance.resolveObjection(meetingFactoryAddr, objectionId);

// 4. Org admin adopts — applies the stored changeData to the RoleRegistry.
const { resultId } = await agent.governance.adoptProposal(meetingFactoryAddr, proposalId);

// …or discards the draft without applying the change.
await agent.governance.discardProposal(meetingFactoryAddr, proposalId);
```

The governance module also exposes indexer-backed reads: `listProposals(processAddress, circleId)`, `listOpenProposalsByOrg(orgId)`, and `getProposal(id)`.

See `packages/agent-sdk/examples/propose-tension.ts` for a runnable end-to-end flow.

## Voting

```ts
// Create a vote on a meeting output
const { voteId } = await agent.voting.create(votingAddr, {
    circleId: 1n,
    outputId: 42n,
    reason: "Approve marketing budget allocation",
    duration: 86400, // 24 hours
});

// Cast a vote (0=Against, 1=For, 2=Abstain)
await agent.voting.cast(votingAddr, { voteId, support: 1 });

// Grant voting weight to an external collaborator
await agent.voting.grantCollaboratorWeight(votingAddr, 1n, "0xAdvisor...", 100n);
```

## Encoding Helpers

For advanced use cases, the SDK exports low-level ABI encoding helpers:

```ts
import {
    ChangeType,
    encodeAmendRole,
    encodeCreateRole,
    encodeElection,
    encodeRemoveRole,
} from "@hollab-io/agent-sdk";

// Build the raw changeData payload for createProposal
const changeData = encodeCreateRole({ circleId: 1n, name: "Ops", purpose: "Operations" });
await agent.governance.createProposal(meetingFactoryAddr, {
    orgId,
    circleId: 1n,
    tensionText: "We need dedicated ops ownership",
    changeType: ChangeType.CreateRole,
    changeData,
});
```

## Design Principles

-   **Framework-agnostic** — Pure TypeScript, works in Node.js, Deno, or browser. No React dependency.
-   **Read via indexer** — All queries go through the Ponder GraphQL API. No expensive RPC calls for reads.
-   **Write via contracts** — All mutations use viem contract actions with proper ABI encoding.
-   **Governance-enforced** — Structural changes must go through the governance module, matching the onchain protocol rules.
-   **Agent-first** — Every method is self-contained with explicit parameters. No shared state, no method chaining required.
